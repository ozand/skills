# Skills

Небольшая коллекция специализированных инструкций для ИИ-агентов. Каждый навык — это папка с файлом `SKILL.md` и дополнительными материалами.

## Доступные навыки

- [`explain-clearly`](skills/explain-clearly/) — объясняет технические и нетехнические темы понятным языком с учётом аудитории, сохраняя смысл, неопределённость и важные ограничения.

## Использование навыка

Попросите агента: «Используй навык `explain-clearly` из `https://github.com/ozand/skills`». Агенту следует прочитать `skills/explain-clearly/SKILL.md` и все файлы, на которые он ссылается. Это разовое использование: оно не устанавливает навык и не гарантирует, что любой агент сможет открыть этот репозиторий.

## Установка для Pi

Pi ищет навыки в `~/.agents/skills/` (для пользователя) и `.agents/skills/` (для проекта). Скопируйте туда **всю** папку `skills/explain-clearly/`, сохранив `SKILL.md` и `references/`. В папке навыка есть копия лицензии MIT — она останется вместе со скопированными файлами. Из корня этого репозитория создайте каталог пользовательских навыков и копируйте только если целевая папка ещё не существует:

```sh
mkdir -p ~/.agents/skills
if [ ! -e ~/.agents/skills/explain-clearly ]; then
  cp -R skills/explain-clearly ~/.agents/skills/explain-clearly
else
  echo 'Папка уже существует; сравните содержимое и получите разрешение перед заменой.' >&2
  exit 1
fi
```

Для установки только в проект используйте `.agents/skills/` вместо `~/.agents/skills/`. Сначала проверьте путь назначения; если `explain-clearly` уже существует, не перезаписывайте её. В активном сеансе после изменений выполните `/reload`; новый сеанс также загрузит навыки заново. Проверьте доступность команды `/skill:explain-clearly` и при необходимости вызовите её вручную. Это шаги для проверки, а не утверждение, что установка уже проверена на вашем устройстве.

Актуальные сведения о поиске и перезагрузке навыков — в [документации Pi](https://github.com/badlogic/pi-mono/blob/main/packages/coding-agent/docs/skills.md).
