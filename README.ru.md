# Навыки для ИИ-агентов

[English](README.md) · [Русский](README.ru.md)

Открытая коллекция навыков, которые помогают ИИ-агентам выполнять конкретные задачи. **Навык** — это набор письменных рекомендаций для определённой задачи; это не отдельное приложение, и агент сможет им воспользоваться, только если поддерживает такой формат и имеет доступ к файлам навыка.

## Каталог

- [**explain-clearly**](skills/explain-clearly/) — помогает объяснять технические и повседневные темы с учётом аудитории, не теряя важный смысл, неопределённость и ограничения безопасности.

## Кому может пригодиться

Тем, кто просит ИИ-помощника объяснить незнакомую идею, переписать непонятный текст или адаптировать объяснение для конкретной аудитории. Навык также может помочь командам, которые хотят задать совместимому агенту единые рекомендации по изложению. Это рекомендации, а не гарантия результата: важные объяснения стоит проверять, а беглый ответ сам по себе не доказывает, что человек всё понял.

## Как использовать

Для разового запроса дайте агенту ссылку на файл [`SKILL.md`](skills/explain-clearly/SKILL.md) и попросите следовать рекомендациям — если агент умеет читать файлы репозитория. Чтобы навык был доступен в будущих сеансах, следуйте инструкциям для установки или обнаружения навыков в вашем агенте. Установка, обнаружение и загрузка работают по-разному в разных агентах; само копирование файлов не означает, что агент загрузил или использовал навык.

Пример, ограничения и инструкции по установке смотрите на странице [explain-clearly](skills/explain-clearly/).
