# Skills

[English](README.md) · Русский

Открытая коллекция skills для ИИ-агентов.

## Skills

- [**explain-clearly**](docs/communication/explain-clearly.ru.md) — помогает понятно объяснять сложные темы, сохраняя важный смысл и неопределённость.

## Использование

Выберите skill и следуйте инструкции на его странице. Можно попросить агента использовать его один раз или установить для будущих сеансов; способ установки зависит от агента.
