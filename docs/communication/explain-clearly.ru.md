# Explain Clearly — понятные объяснения

[English](explain-clearly.md) · Русский

**Explain Clearly помогает ИИ объяснять понятнее.** Вместо названия ошибки агент может рассказать, что могло произойти и что можно сделать. Если причина неизвестна, он не должен выдавать догадку за факт.

**Файлы skill:** [открыть папку самого skill](../../skills/communication/explain-clearly/) · [прочитать `SKILL.md`](../../skills/communication/explain-clearly/SKILL.md)

## Пример

**До:** «Ошибка кэша. Очистите кэш».

**После:** «Возможно, браузер показывает сохранённую старую картинку. Очистка кэша может помочь загрузить новую, но не исправит картинку, если она неверна на самом сайте».

Это вымышленный пример, а не установленная причина конкретной проблемы. [Другие примеры](../../skills/communication/explain-clearly/references/examples.md).

## Как использовать

**Один раз:** дайте агенту доступ к [`SKILL.md`](../../skills/communication/explain-clearly/SKILL.md) и попросите: «Прочитай этот skill и объясни мой вопрос по его правилам».

**Для будущих сеансов:** попросите агента установить папку самого skill `explain-clearly`, ссылка на которую приведена выше, включая `SKILL.md` и `references/`, и скопировать рядом корневой файл `LICENSE` репозитория. Способ установки зависит от системы агента. Существующий skill нельзя перезаписывать без проверки и разрешения; после установки проверьте, что система его обнаружила.

Для агента: различай разовое применение и установку; проверь документацию своей системы и сообщи, куда скопированы файлы и нужна ли перезагрузка. Не утверждай, что skill загружен или используется, без проверки.

### Установка в Pi

Из корня репозитория для текущего пользователя:

```sh
mkdir -p ~/.agents/skills
if [ ! -e ~/.agents/skills/explain-clearly ] && [ ! -L ~/.agents/skills/explain-clearly ]; then
  cp -R skills/communication/explain-clearly ~/.agents/skills/explain-clearly && cp LICENSE ~/.agents/skills/explain-clearly/LICENSE
else
  echo 'Папка уже существует; сравните содержимое и получите разрешение перед заменой.' >&2
  exit 1
fi
```

Если копирование завершилось ошибкой или было прервано, в папке назначения могут остаться не все файлы. Проверьте её содержимое перед удалением или повторной попыткой; не удаляйте нужные вам файлы.

Для установки только в проект используйте `.agents/skills/` вместо `~/.agents/skills/`. После изменения Pi поддерживает `/reload`; проверьте доступность `/skill:explain-clearly` и сообщения о совпадении имён. Подробнее — в [документации Pi](https://github.com/badlogic/pi-mono/blob/main/packages/coding-agent/docs/skills.md). Установка на вашем устройстве не проверялась.
