# Skills for AI agents

[English](README.md) · [Русский](README.ru.md)

An open collection of skills that help AI agents perform specific tasks. A **skill** is a set of written guidance an agent can consult when doing a particular kind of task; it is not a separate app, and an agent must support and have access to skills for it to use one.

## Catalogue

- [**explain-clearly**](skills/explain-clearly/) — helps explain technical and everyday topics in audience-aware language, without losing important meaning, uncertainty, or safety limits.

## Who it may help

Useful for people who ask an AI assistant to explain an unfamiliar idea, rewrite a confusing passage, or adapt an explanation for a particular audience. It can also help teams who want to give a compatible agent consistent writing guidance. It is guidance, not a guarantee: review important explanations, and do not treat a fluent answer as proof that someone understood.

## How to use

For a one-off request, point your agent to the skill's [`SKILL.md`](skills/explain-clearly/SKILL.md) and ask it to follow the guidance, if it can access repository files. To make the skill available in future sessions, follow the instructions for your agent to install or discover skills. Installation, discovery, and loading differ between agents; placing files somewhere does not by itself mean an agent has loaded or used them.

For the skill's example, limits, and installation details, see [explain-clearly](skills/explain-clearly/).
